# Real-Time-Yoga-Pose-Correction-System-Using-Pose-Estimation-with-Audio-Feedback
Practicing yoga pose without supervision can lead to improper alignment. This paper presents a real-time yoga pose correction system that evaluates posture through a standard webcam. MediaPipe Pose detects 33 body landmarks, from which six joint-angle features (left and right knee, hip, and shoulder) are computed.
